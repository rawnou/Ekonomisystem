# Bokföring, moms och rapporter

Separat prov för Testkompassen AB med fiktiva uppgifter och öppet räkenskapsår 2026-01-01–2026-12-31. Facit skrevs före första körningen. Belopp i rapporten anges i kronor. Testlogg och API använder ören. A1 skapades i det riktiga gränssnittet. Efterföljande bokningar och exporthämtning gick över HTTP. Grundboken och rapportvyn lästes i Chromium.

[Facit och fiktiva indata](facit.json) · [Testskript](kor.mjs) · [Observerade svar och exporterade rader](korning.jsonl) · [Rapportvy med A1–A6 bokförda](rapporter.png)

## Kör om

Kör från repots rot med Node.js 24, `iconv` och vid gränssnittsprov Chromium samt `playwright-core`. Anpassa sökvägarna om webbläsaren och modulen är installerade på annan plats. Katalogen från `mktemp` tar emot de två råa exportfilerna och en skärmbild. Skriptet skapar och stänger tre separata temporära SQLite-databaser.

```bash
set -o pipefail
balans_qa_output="$(mktemp -d)"
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright-core \
  CHROMIUM_EXECUTABLE=/usr/bin/chromium \
  BALANS_QA_OUTPUT="$balans_qa_output" \
  node testunderlag/bokforing/kor.mjs | tee "$balans_qa_output/korning.jsonl"
```

Utelämna `PLAYWRIGHT_MODULE` för en körning via HTTP där R-04 blir **blockerat** och R-06 utgår. Skriptet kontrollerar också att de fel som anges som underkända kan reproduceras. Exitkod 0 betyder att de dokumenterade observationerna återkom. Exporternas kontrollsummor kan variera med datumen för körning och registrering.
