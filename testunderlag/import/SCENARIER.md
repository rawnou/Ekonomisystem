## Leverantörer, kostnader, bank och import

Fiktivt bolag Testkompassen AB, öppet räkenskapsår 2026. Bokföring från tom databas i en separat temporär katalog med egen server, egna sessioner och lokal startbackup. Genomfört med Node.js 24.22.1, SQLite 3.53.4 och Chromium 156.0.8078.79 i Playwright 1.62.0 på Debian 13. Löpande belopp nedan anges i kronor. Körloggen använder ören och saldon med debet som positivt tecken. Leverantörsfaktura och kvitto framställs som PDF av de fiktiva textunderlagen i körningen. Bank, KDP och Adtraction simuleras med CSV-filer. Ingen kontakt med externa tjänster behövs.

Kör från projektroten med Node 24+, Python med Playwright och Chromium. Vid en annan Chromium-sökväg anges `BALANS_TEST_CHROMIUM`.

```bash
set -o pipefail
python testunderlag/import/prova.py | tee testunderlag/import/korning.txt
```
